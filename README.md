xxDK Language Bindings
======================

This repository contains bindings to the xxDK for various languages. By default, the core xxDK Go library is built as a shared library, with a C interface for use by other language bindings.

## Shared Library / C Bindings

The shared library is generated by Cgo from the module in `sharedcgo/` (see _Building and Testing_ below). This will emit a generated header file, but it is recommended to instead use the manually-written `xxdk.h` in the root directory.

`tests-c/` contains automated tests for the C bindings, and `examples-c/` contains examples translated from the Go [official examples](https://git.xx.network/xx_network/xxdk-examples/-/tree/master/other-examples). Tests and examples are written in C++ rather than C, in order to make use of C++17's standard-library filesystem API.

Documentation for the C bindings can be found as comments in `xxdk.h`.

## Building and Testing

The `Makefile` in the root directory drives compilation and testing of all language bindings. Running `make` or `make all` from the root directory will do the following:

- Build the Cgo shared library;
- Build all C/C++ examples;
- Build and run all C/C++ automated test suites.

By default, the shared library will be built for Linux x86_64. To override this behavior, set the environment variables `GOOS` and `GOARCH` prior to running `make`; e.g. `GOOS=darwin GOARCH=arm64 make`.

The tests require an NDF for connecting to the network. If the environment variable `XX_TEST_NDF_PATH` is set, they will attempt to read the NDF from that path; otherwise, they will look for a file named `ndf.json` in the working directory.

`make clean` will remove all compiled binaries and cMix state directories generated by the automated tests.

Other make targets and variables are provided for more granular control over the build; see the makefile for details.

## Other Language Bindings

There are early draft C# and Rust bindings in `xxdk.NET/` and `xxdk-rs/` respectively. These are currently non-functional, pending completion of the C bindings.
